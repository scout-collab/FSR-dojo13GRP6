# Favorite Soils Report (FSR 2)

A simple group website designed for GitHub Pages.

## Publish
1. Upload **the contents** of this folder to the root of the GitHub repository (`index.html`, `blog.html`, `taylor.html`, `cody.html`, `nicole.html`, `styles.css`, `assets/`).
2. In repository Settings → Pages, select **Deploy from a branch**, `main`, `/(root)`, then Save.
3. Visit `https://scout-collab.github.io/tboyd.github.io/`.
